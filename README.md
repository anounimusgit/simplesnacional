# Consulta Simples Nacional - versão web

Esta é a versão sem Python, pronta para GitHub Pages.

## Como publicar

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Vá em Settings > Pages.
4. Em Source, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/root`.
6. Aguarde o GitHub gerar o link.

## Observação

A consulta é feita diretamente no navegador usando APIs públicas. Se uma API bloquear CORS ou ficar indisponível, o resultado pode falhar ou cair no fallback disponível.
